# 质量检查清单

> 做完设计后逐条对照。P0必须全过，否则打回修改。
> 依据 `brand-dna.md`（KAI 设计体系：原研哉理念 × 色板）。

---

## P0（必须全过）

任何一条不过就要改：

- [ ] 全部颜色来自色板（或其透明度变体 / 既定派生色），**无任何新增色值**
- [ ] 配色比例合规：近白 65–70% / 藏青 20–25% / 中性 8–10% / 姜黄 ≤5%
- [ ] 姜黄只出现在下划线、徽章、高亮、数据点这类「索引/强调」位置，绝不大段铺色
- [ ] 去掉颜色（灰阶）后画面依然成立——黑白先行
- [ ] 一屏只有一个焦点，没有两个主角抢戏
- [ ] 背景用近白 `#FCFCFC`，非纯黑 `#000` 纯白 `#fff`
- [ ] 层级只靠字号、字重、留白——正文没有用藏青/姜黄做层级
- [ ] 留白达标：标题四周 ≥ 标题高度 1 倍；段落间距 ≥ 行高 1.5 倍；卡片内边距 ≥ 最小字号 2 倍
- [ ] 字体只用思源黑体/思源宋体/系统栈——无花哨标题字、手写体、艺术字、大号水印装饰字
- [ ] 没有使用禁忌清单里的任何元素（蓝紫渐变/glassmorphism/bounce动画/neon/满屏装饰）
- [ ] 有响应式（至少900px断点），移动端留白未消失
- [ ] 每个section布局形式不同
- [ ] clamp()做fluid sizing
- [ ] 没有使用任何HTML默认样式（默认blockquote、默认border-left引用、无样式ul/ol、默认table）——所有组件必须从components.md选用

---

## P1（应过）

尽量满足，提升品质：

- [ ] 至少一处「地平线式」构图——大背景 + 小主体，主体占画面 25%–35%
- [ ] 视觉层级清晰：字号梯度 ≥3 级，字重对比明显（400 vs 700–900）
- [ ] 有克制的纸感/噪点材质（低对比纹理，不炫技）
- [ ] 有Scroll Reveal动效 + stagger延迟（仅 opacity/transform）
- [ ] 至少一处用炭黑 `#0C0C0C` 手绘线压住主体轮廓
- [ ] ::selection用姜黄高亮 + 炭黑文字
- [ ] 章节之间有呼吸感——不是内容塞满

---

## P2（加分）

锦上添花：

- [ ] 一个全宽藏青面板打破节奏（一页最多1~2个，近白文字，姜黄只做一处焦点）
- [ ] 装饰元素克制——每加一个元素前问过「删掉它，意思还在吗」
- [ ] 图片溢出容器边界制造一处视觉惊喜
- [ ] prefers-reduced-motion尊重
